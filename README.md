## 🗄️ SQL Projects

### Olist E-Commerce — SQL Case Study

**[View Project →](https://github.com/UlasSY/SQL-Case-Studies-Olist)**

End-to-end SQL analysis of the **Olist Brazilian E-Commerce dataset**, working with a relational database containing approximately **100K+ orders**.

The project focuses on extracting business insights through **PostgreSQL**, relational data analysis, multi-table JOINs, aggregations, customer analysis, payment behavior, and logistics performance.

**Technologies & Concepts**

`PostgreSQL` `SQL` `JOINs` `GROUP BY` `HAVING` `Aggregations` `CTEs` `Subqueries` `Relational Database` `Business Analysis`

**Analysis Areas**

* Customer & order analysis
* Product & category performance
* Payment behavior
* Revenue & sales metrics
* Delivery & logistics performance
* Multi-table relational analysis
* Business-oriented SQL scenarios
